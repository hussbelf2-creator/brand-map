# براند ماب · Brand Map (React)

منصة لعبة «براند ماب» لبناء استراتيجية العلامة التجارية: ٨ محاور، ٣٥ بطاقة، ٣ بطاقات ذهبية — مبنية بـ **React 18 + Vite**.

## التشغيل

```bash
npm install
npm run dev        # خادم تطوير على http://localhost:5173
npm run build      # يبني dist/index.html كملف واحد جاهز للنشر
```

- **داخل Claude:** يُنشر `dist/index.html` كـ Artifact مع صلاحيات `capabilities.json` (قاعدة البيانات، المستخدم، التحميل، الغرف اللحظية، الذكاء الاصطناعي).
- **خارج Claude:** يعمل في «الوضع المحلي»: الجلسات على الجهاز فقط، بلا مزامنة ولا ذكاء اصطناعي.

## البنية

```
src/
├── engine/engine.js      محرّك اللعبة: البيانات، طبقة المحتوى، الجلسة والمزامنة،
│                         المستشارون، الباقات، الصوت، الطاولة ثلاثية الأبعاد (Three.js)
├── ui/                   مكوّنات مشتركة: الأيقونات، النوافذ والدرج والإشعارات،
│                         اللوحات، محرّر الأسطر، خطّاف الاشتراك في المحرّك
├── nav.js                التنقل بين الشاشات عبر الرابط
├── App.jsx               الإطار العام
└── features/
    ├── home/             الصفحة الرئيسية
    ├── start/            البداية: التسجيل، جلسة جديدة، انضمام، رفع صور اللعبة المطبوعة
    ├── plans/            الباقات وطلب الاشتراك
    ├── play/             الطاولة: البطاقات، المؤقت، التأكد، التعارض، لوحة الاستلام
    ├── intake/           بطاقة المشروع والحضور الرقمي
    ├── scan/             قراءة صور لوحة الاستلام
    ├── dashboard/        لوحة المتابعة
    ├── pages/            الصفحات النهائية والمسارات والمشاريع
    ├── digital/          الحضور الرقمي في لوحة المتابعة
    ├── docs/             وثيقة المشروع (Word / HTML / JSON)
    ├── lessons/          الدروس والرسومات
    ├── agents/           وكيل ذكي لكل بطاقة
    ├── ai/               المساعد الذكي للعبة
    ├── consult/          المستشارون الحقيقيون: الحجز ولوحة المستشار
    └── admin/            لوحة الإدارة الكاملة
```

### كيف تتدفق البيانات
- **المحرّك** يملك الحالة: الجلسة `S`، والمستخدم، وحالة الواجهة `ui`. يُعدَّل فقط عبر دواله (`patch`، `openSession`، `setUI`…).
- كل تغيير، محلياً أو قادماً من أعضاء الفريق لحظياً، يرفع «رقم إصدار»، والمكوّنات تشترك فيه عبر `useEngine()` (مبني على `useSyncExternalStore`)، فيُعاد رسم ما يلزم.
- الحالة المؤقتة الخاصة بمكوّن واحد (حقل نص، تبويب) تبقى في `useState` داخله.

## فحص الكود


## ملاحظات للمطوّرين
- `src/engine/engine.js` هو مصدر الحقيقة لمنطق اللعبة. ولّدناه مرة واحدة من النسخة السابقة، ويُعدَّل الآن مباشرة.
- `ARCHITECTURE.md` يوثّق حدود كل وحدة وما تصدّره، والقواعد المتبعة في المكوّنات.
- `capabilities.json` يحوي صلاحيات النشر وقواعد قاعدة البيانات (١٨ قاعدة).
- `dist/index.html` نسخة مبنية جاهزة للنشر.
